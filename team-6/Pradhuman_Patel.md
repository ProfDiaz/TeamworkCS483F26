## My Contribution

I created this Markdown file to share practical tips for using Git and GitHub. The goal is to help everyone on the team commit cleanly, collaborate without overwriting each other's work, and avoid the most common mistakes beginners run into.




## Tip

Always pull before you push. Before you start working on the project, run git pull to download the latest changes your teammates have made. This keeps your copy of the project up to date and greatly reduces the chance of merge conflicts, which happen when two people edit the same part of a file at the same time.
