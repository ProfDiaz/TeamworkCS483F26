## Syntax Errors (Compile-Time Errors)

- **What they are:** Violations of the grammatical and structural rules of a programming language.
- **Common causes:** Missing semicolons, unclosed brackets or parentheses, misspelled keywords, or wrong indentation.
- **Consequences:** The code fails to compile or run at all.

**Example:**

```python
print("Hello"   # missing closing parenthesis -> SyntaxError
```
